RUNNING THIS DEMO

This page calls a small local backend proxy at http://localhost:8787/api/messages instead of calling Anthropic's API directly from the browser — direct browser-to-API calls are blocked by CORS and would require exposing a real API key in this file's source. Start the proxy first: cd agentdesk-server && cp .env.example .env (add your key) && node server.js, then open/reload this page. No npm install is required — the proxy uses only Node's built-in http/https modules.

PIPELINE

Ticker selection → generateMarketData() synthesises a price/volume/technical snapshot (this demo uses a simulated feed in place of a live NSE feed, matching the brief's "live or simulated market data source" dependency). Three agents then run concurrently via Promise.allSettled, each receiving only the data slice relevant to its dimension — they do not see each other's reasoning until the synthesis step, which is what makes them independent rather than one model role-playing three opinions in sequence.

THE THREE AGENTS

Momentum Agent (price_momentum) reasons over RSI, moving-average crossovers and 5-day price change. Volume Agent (volume_anomaly) reasons over volume-vs-30-day-average deltas to flag accumulation/distribution. Sentiment & Fundamentals Agent (sentiment_fundamental) is the RAG-grounded agent: it queries a synthetic corpus of filings/earnings/FII-flow notes, receives the top-scored chunks with source IDs, and must cite them — it is instructed to answer only from retrieved text, not general knowledge, so an unsupported claim is a contract violation, not a stylistic choice.

RETRIEVAL

retrieveDocs() scores each corpus chunk by lexical overlap with the query (ticker + intent keywords) and returns the top two. Each returned chunk carries a source_id, publication label and date, which the Sentiment Agent must reference in its citations array — visible to the user as the paper-colored cards above.

SYNTHESIS & PERSONALIZATION

The Synthesis Agent receives all three structured agent outputs plus the user's stated risk tolerance and current portfolio weights, and is instructed to (a) reconcile any disagreement between agents explicitly rather than silently averaging it away, and (b) let the risk profile change the action, not just the tone. The "Compare risk profiles" control re-runs synthesis over the same three agent outputs for all three profiles side by side, so a judge can see the personalization take effect on identical market inputs without re-fetching data.

GRACEFUL DEGRADATION

Selecting "Missing volume feed" nulls the volume fields before they reach the Volume Agent; the agent detects the gap in code (not by asking the model to guess) and returns INSUFFICIENT_DATA at zero confidence with no API call made for that agent — cheaper and honest. Selecting "Conflicting signals" biases the technical snapshot bullish while surfacing a bearish risk-factor filing to the Sentiment Agent, so the two disagree; the Synthesis Agent is required to populate conflicts_noted instead of masking the disagreement.

METRICS LOGGED PER SESSION

Average agent latency (ms, measured client-side around each fetch), average signal confidence across agents that returned data, and portfolio concentration (a Herfindahl-Hirschman index over position weights, 0 = fully diversified across holdings, 1 = single-position). Logged sessions persist across reloads via the artifact's key-value storage.

LIMITS OF THIS MVP

Market data, the filing corpus and tickers are synthetic and clearly labeled as such — this is a reasoning-and-orchestration demo, not a live trading signal, and nothing here is real investment advice. A production version would swap generateMarketData() for real NSE/SEBI feeds and the corpus for a real vector index.
